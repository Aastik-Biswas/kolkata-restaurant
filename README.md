# Zomato Kolkata Restaurant Data Analysis

## Project Overview
This is a data cleaning and exploratory data analysis project using a Kolkata restaurant dataset.

The dataset contains 4,923 restaurant records and 19 columns.


## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Google Colab

## Data Cleaning
The notebook:
1. Checks dataset dimensions and data types.
2. Identifies missing values.
3. Removes duplicate rows.
4. Converts rating fields into numeric values.
5. Converts review and cost fields to numeric values.
6. Handles missing descriptive text values.

## Analysis Performed
- Summary statistics
- Top restaurant areas
- Most common cuisines
- Restaurant cost distribution
- Dinner rating distribution
- Delivery rating distribution
- Home delivery, takeaway, indoor seating and veg-only percentages
- Dinner rating vs average cost
- Dinner reviews vs rating
- Top-rated restaurants
- Most-reviewed restaurants
- Average restaurant cost by popular area
- Correlation analysis
- Automatically generated key findings
