# Zomato Kolkata Restaurant Data Analysis

## Project Overview
This is a beginner-friendly data cleaning and exploratory data analysis project using a Kolkata restaurant dataset.

The dataset contains 4,923 restaurant records and 19 columns.

The project focuses entirely on understanding and visualizing the data. No machine learning is used.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Google Colab

## Data Cleaning
The notebook:
1. Checks dataset dimensions and data types.
2. Identifies missing values.
3. Removes duplicate rows.
4. Converts rating fields into numeric values.
5. Converts review and cost fields to numeric values.
6. Handles missing descriptive text values.

## How to Run in Google Colab
1. Upload `Zomato_Kolkata_EDA_Analysis.ipynb`.
2. Run the notebook from the first cell.
3. When prompted, upload `Zomato_Kolkata_Restaurants.csv`.
4. Run all remaining cells in order.
